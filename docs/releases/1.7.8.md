# XRoute 1.7.8

For MikroTik RouterOS 7 on ARM64 routers and x86_64 CHR.

- Upload large recovery archives through the panel. The panel checks for duplicates before sending the file.
- Changing container memory limits no longer requires reopening Settings after the restart.
- You can select WireGuard or Reverse VLESS in a routing policy without adding a provider subscription.
- You can apply changes to a Reverse VLESS policy before its first connection if the policy serves no LAN clients.
- Remote client access includes manually configured internal subnets and excludes ignored networks and container links.

Use the offline ZIP for a new installation. For an existing installation, upload the TAR for your architecture in the panel. [Installation guide](https://github.com/Ati054/xroute/blob/v1.7.8/docs/INSTALL.md)

Для RouterOS 7 на роутерах MikroTik ARM64 и виртуальных машинах x86_64 CHR.

- Через панель можно загружать большие резервные копии. Перед отправкой панель проверяет, есть ли такой архив на диске.
- После смены лимитов памяти контейнера открывать настройки повторно не нужно.
- WireGuard и Reverse VLESS можно выбрать в маршрутном листе без подписки провайдера.
- Изменения листа Reverse VLESS без локальных клиентов можно применить до первого подключения.
- Для удалённых клиентов доступны внутренние подсети из настроек. Служебные и игнорируемые подсети скрыты.

Для новой установки используйте офлайн-комплект ZIP. Для обновления загрузите TAR для вашей архитектуры через панель. [Инструкция по установке](https://github.com/Ati054/xroute/blob/v1.7.8/docs/INSTALL-RU.md)
